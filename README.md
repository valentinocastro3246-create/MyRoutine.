# Mi plan del día

App web para organizar el día: horario de 24 horas por día de la semana (con tarjetas que se arrastran), registro de agua, contador de calorías con buscador de alimentos y hobbies.

Los datos se guardan en el navegador de cada persona (localStorage).

## Archivos

- `index.html`: la página
- `style.css`: los estilos
- `app.js`: la lógica
- `.nojekyll`: le indica a GitHub Pages que sirva los archivos tal cual

## Publicar en GitHub Pages

1. Subir estos archivos a la raíz de un repositorio público.
2. Settings > Pages > Branch `main` > carpeta `/ (root)` > Save.
3. Esperar uno o dos minutos y abrir el link que aparece.
